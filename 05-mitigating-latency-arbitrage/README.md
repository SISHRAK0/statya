# Защита от латентного арбитража в краткосрочных бинарных рынках: динамические комиссии, закрытие по средней цене и RFQ-аукционы

*Mitigating Latency Arbitrage in Short-Horizon Binary Markets: Dynamic Fees, Averaged Settlement, and RFQ Auctions*

## Идея
Три механизма из Uniswap / RFQ, перенесённые на Polymarket:
1. **Закрытие по средней цене за последние N секунд** (как TWAP в Uniswap v3) — последние тики почти ничего не решают, арбитраж в конце окна теряет смысл. Главная новая идея.
2. **Динамическая комиссия по p, τ и σ** (как hooks в Uniswap v4).
3. **RFQ с голландским аукционом** (как UniswapX) — нет устаревших котировок, задержка не приносит денег.

Сравнить все три с текущей комиссией Polymarket в одной модели и проверить на реальных данных.

## Известные слабые места
- Усреднение меняет контракт (азиатский бинарный опцион) и растягивает арбитраж, а не убирает: к концу окна большая часть среднего уже известна.
- RFQ на истории не проверить — только симуляция.
- Данные: сделки/стакан Polymarket с точными метками + тики Binance/Chainlink с мс, до и после января 2026.

# TLDR

## Выбранная тема

**Молчаливый сговор, шаг цены и субсидии ликвидности в маркет-мейкинге рынков предсказаний**

*Tacit Collusion, Tick Size and Liquidity Subsidies in Prediction-Market Making*

Объединяет [06](06-liquidity-rewards-game/) (награды за ликвидность), [07](07-tick-size-switch/) (смена тика) и [10](10-mm-tournament/) (турнир стратегий — раздел-симуляция).

**Вопрос:** держат ли маркет-мейкеры Polymarket широкий спред без сговора, как его поддерживает крупный тик и как его ломает пул наград; сколько ликвидности покупает $1 субсидии.

**Почему эта:** новизна 4/5, чистая идентификация (тик 0.01→0.001 у краёв не возвращается назад → рынки с разным тиком при одной цене; полосы 0.1¢ на Kalshi; тысячи изменений пула наград), нет альфы — статья про дизайн рынка.

**Запасная:** [09](09-excess-volatility-martingale/) — избыточная волатильность ограниченных мартингалов (данные есть уже сейчас); сначала прочитать Xu, SSRN 7012278, на пересечение.

## План

1. **Сбор данных — начать сразу** (2–3 месяца): стаканы рынков с наградами и у порогов тика (websocket book + `tick_size_change`), параметры наград (`/rewards/markets`) ежедневно, тики/стаканы Kalshi в полосах 0.1¢.
2. **История без ожидания:** пулы наград из Wayback (~22 тыс. снимков, 2024–2026); кучкование сделок на целых центах после смены тика по on-chain сделкам (тест в духе Christie–Schultz).
3. **Теория:** поминутный конкурс Таллока за пул с издержками adverse selection + конкуренция за очередь на дискретной сетке; повторная игра → условие устойчивости сговора.
4. **Симуляция:** довести прототип турнира (`10-mm-tournament/scripts/mm_tournament.py`), откалибровать по данным, проверить устойчивость вывода про тик к определению подрезания.
5. **Эмпирика:** разрыв по историческому минимуму цены (тик 0.01 vs 0.001 при одной цене); изменения пула внутри рынка; главный тест — взаимодействие «пул × тик» на спред и глубину.
6. **Вывод для платформы:** ликвидность за $1 субсидии, оптимальные max spread / форма балла.
7. **Текст:** черновик → arXiv / SSRN (q-fin.TR, econ.GN).

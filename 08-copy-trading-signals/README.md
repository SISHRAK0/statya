# Копитрейдинг на прозрачных кошельках: игра сигналов

*Copy Trading on Transparent Ledgers: Signaling, Reputation, and Bait-and-Switch on Polymarket*

## Идея
Все кошельки видны, успешных трейдеров копируют боты и люди. Игра информированного трейдера против последователей: торговать открыто (последователи двигают цену), дробить по кошелькам, bait-and-switch (купить, привлечь последователей, продать им). Игра сигналов с репутацией: при каком размере аудитории выгодно блефовать.

- Эмпирика: граф «лидер → последователи» по задержкам между сделками; цена следования, частота разворотов после притока последователей, доходность последователей.
- Возможно только при прозрачности блокчейна. Описывает экосистему, а не стратегию.

## Заметки
- Классика: Benabou & Laroque (1992) insiders, gurus, credibility; копитрейдинг eToro (Apesteguia–Oechssler–Weidenholzer).
- Главная ловушка: одновременная реакция на новость ≠ копирование → нужна идентификация (тихие рынки и т.п.).
- Данные on-chain, точность до блока (~2 с). Публиковать только агрегаты.

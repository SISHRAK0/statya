# Смена шага цены как естественный эксперимент: сговор или подрезание

*Tick Size Switches as a Natural Experiment: Tacit Collusion vs. Undercutting in Prediction Markets*

## Идея
Тик Polymarket 0.01, у краёв (~0.04/0.96) уменьшается до 0.001 (сверить по `tick_size` / событию `tick_size_change`). Крупный тик: мейкеры стоят в очереди на одной цене, спред зафиксирован сеткой — «кооперация». Мелкий тик: выгодно встать на 0.001 лучше соседа — «предательство», спред сжимается.

- Метод: разрыв на пороге смены тика по всем рынкам, которые его пересекают: спред, глубина, отмены, длина очередей.
- Теория: конкуренция за место в очереди на дискретной сетке, ограниченный актив с вероятностной интерпретацией.

## Заметки
- RDD по цене опасен: около 0.04 рынок почти разрешён, p(1−p) мало → лучше разрыв во времени в момент переключения у одного рынка.
- Литература: Yao & Ye (RFS 2018) queue rationing under price controls; Tick Size Pilot.
- Бонус: при тике 0.01 актив со стоимостью 0.003 не торгуется ниже 0.01 → крупный тик может механически давать часть favourite-longshot bias.
- Нужен стакан — собирать вперёд; переключения частые.

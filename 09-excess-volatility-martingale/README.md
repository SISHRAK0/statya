# Тест на избыточную волатильность для ограниченных мартингалов

*Excess Volatility in Prediction Markets: Noise-Robust Tests of the Bounded-Martingale Restriction*

## Идея
Если p_t — мартингал на [0,1] и рынок разрешается в 0/1, то E[Σ(Δp)²] = p₀(1−p₀) (ортогональность приращений) — ограничение без параметров.

- Вклад: на тиковых данных наивная сумма квадратов раздута микроструктурным шумом (bid-ask bounce) → оценки, устойчивые к шуму (TSRV, pre-averaging, realized kernels), их асимптотика для ограниченного процесса с поглощением в 0/1.
- Результат: чистая избыточная волатильность по тысячам рынков, по категориям, ликвидности, времени до разрешения. Сколько «лишнего движения» — шум, сколько — чрезмерная реакция.

## Заметки
- Augenblick & Rabin (QJE 2021) — проверить, на каких данных и что уже сделано; Augenblick–Lazarus–Thaler (overinference).
- Сумма по одному рынку — одна реализация с огромной дисперсией; мощность — из агрегации, рынки одного события коррелированы.
- Премия за риск / favourite-longshot bias ломают мартингальность под P.
- Данные: сделки on-chain полностью + минутная история цен; исторический стакан не обязателен.

# statya

Репозиторий статей про рынки предсказаний (Polymarket). Одна папка — одна тема.

| Папка | Тема |
|---|---|
| [01-latency-arbitrage](01-latency-arbitrage/) | Латентный арбитраж на краткосрочных криптоконтрактах Polymarket |
| [02-liquidation-barrier](02-liquidation-barrier/) | Учитывают ли рынки предсказаний риск ликвидаций (on-chain плечо и барьерные контракты) |
| [03-macro-shocks-btc](03-macro-shocks-btc/) | Шоки на рынках предсказаний как торговый сигнал: опережают ли макро-вероятности BTC |
| [04-optimal-taker-fees](04-optimal-taker-fees/) | Оптимальные комиссии тейкера при латентном арбитраже |
| [05-mitigating-latency-arbitrage](05-mitigating-latency-arbitrage/) | Защита от латентного арбитража: динамические комиссии, закрытие по средней цене, RFQ |

В каждой папке: `README.md` — идея и заметки из обсуждения, `RESEARCH.md` — обзор литературы, данных и методологии, `scripts/` — численные прикидки (где есть).
